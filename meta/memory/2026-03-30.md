### 3. Git Workflow Rules Were Added to AGENTS.md

This is critical. Read `AGENTS.md` — it now has a full **Git & GitHub Workflow** section. Here is the summary:

**What you are allowed to do on `main`:**
- Read code
- Run cron jobs
- `git fetch origin` and `git pull origin main`

**What you are never allowed to do on `main`:**
- Push directly — not even a small fix
- Force-push, reset, or rewrite history

**How to do any development work:**
1. `git checkout main && git pull origin main`
2. `git checkout -b feature/your-feature-name` (or `fix/name`)
3. Write the code
4. Write at least one new test in `tests/` for the new feature
5. Run the full test suite: `python3 tests/test_manifold.py && python3 tests/test_automation.py`
6. Fix anything that fails — do not skip
7. Only after ALL tests show ✅: push the branch and open a PR to main
8. Do not merge your own PR — wait for human review

**Git sync — do this on every heartbeat:**
```bash
git fetch origin
git pull origin main   # if you are on main
```

**Git sync — do this at the start of every cron job session:**
```bash
git fetch origin && git checkout main && git pull origin main
```
